User Manual — Windows

Polly Autogen 操作マニュアル

Excelの台本を Amazon Polly でナレーション音声に変換し、PowerPoint に自動再生の音声として埋め込むまでの一連の操作をまとめています。インストールからアンインストールまで、上のメニューから該当の章に移動できます。

対応OS
Windows 11
音声合成エンジン
Amazon Polly
既定リージョン
ap-northeast-1(固定)
出力先アプリ
PowerPoint(.pptx)

クイックリファレンス

一般的な作業の流れは 1 → 9 の順です。すでに用意した .txt ファイルを直接音声化したい場合は 10 を参照してください。

01

インストール

配布された実行ファイルを起動するだけの、ワンクリックインストールです
  1. 配布された Polly Autogen Setup *.exe(例: Polly Autogen Setup 1.0.0.exe)をダブルクリックして実行する。
  2. Windows のセキュリティ警告(SmartScreenなど)が表示されることがあります。表示された場合は「詳細情報」→「実行」を選ぶ。
  3. インストールはウィザード画面の操作なしに数秒で完了する(1クリックインストール)。管理者権限は不要で、ユーザーごとにインストールされる。
  4. 完了すると、デスクトップとスタートメニューに「Polly Autogen」のショートカットが自動的に作成される。
ⓘ

途中で保存先や設定を選ぶ画面はありません。ショートカットの作成まで含めて自動的に行われます。

02

起動

メインウィンドウが開き、Amazon Polly の音声一覧を自動取得します
  1. デスクトップまたはスタートメニューの「Polly Autogen」アイコンをクリックする。
  2. メインウィンドウ(タイトル「Polly Autogen GUI」)が開く。
  3. 起動と同時に、Amazon Polly から利用できる音声の一覧を自動的に取得する。取得が完了するまで 変換開始 ボタンは押せない(グレー表示)。
ⓘ

音声一覧の取得にはインターネット接続と、次の章で設定する AWS の認証情報が必要です。未設定の場合は取得に失敗し、ログ欄にエラーが表示されます。リージョンは ap-northeast-1(東京)に固定されており、変更はできません。

03

AWSアカウントの設定

Amazon Polly を呼び出すためのアクセスキーを登録します

画面最上部の「設定」セクションで、AWS のアクセスキーを登録します。

  1. 「設定」セクションの AWSアカウントの設定 をクリックする。
  2. ダイアログが開く。すでに保存済みの値があれば、Access Key ID と Secret Access Key の欄に自動的に読み込まれる。
  3. 2つの欄に、AWS の IAM ユーザーが持つ Access Key ID と Secret Access Key をそれぞれ入力する。どちらも伏字にならないプレーンテキスト欄なので、入力後にそのまま見直せる。
  4. 保存 をクリックする。ユーザーフォルダの ~/.aws/credentials ファイルの [default] セクションだけが更新され(他のプロファイルやコメントはそのまま残る)、ファイルが無ければ新規に作成される。
⚠

Secret Access Key は第三者に見せたり共有したりしないでください。入力欄がマスクされない仕様のため、画面共有中の操作には注意してください。

上級者向け設定ファイルを直接編集する

複数のプロファイルを使い分けたい場合など

設定ファイルを編集 をクリックすると、~/.aws/credentials が OS に関連付けられたテキストエディタで開きます(ファイルをダブルクリックした場合と同じ挙動)。ファイルが存在しない場合は、空の [default] のひな形を作成してから開きます。

04

トークスクリプト(Excel)ファイル選択

Excel の台本シートから、ページごとのテキストを取り込みます
ⓘ

取り込む Excel ファイルには 「トークスクリプト」という名前のシートが必要です。A列にページ番号、F列に読み上げるスクリプト本文を入力しておいてください。1行目は見出し行として無視され、A列かF列のどちらかが空の行は読み込まれません。

  1. 「台本(Excel)からテキストを作成」セクションの Excelファイルを選択 をクリックする。
  2. ファイル選択ダイアログで .xlsx / .xls ファイルを選ぶ。
  3. Excel ファイルと同じ場所に、ファイル名と同じ名前の作業フォルダが提案される。同名フォルダが既にある場合は、既存フォルダを誤って上書きしないよう (2) (3) … と自動的に別名になる。
  4. 「作業フォルダを選択してください」という確認ダイアログが表示されるので OK を押す。
  5. 続けて開くフォルダ選択ダイアログで、提案されたフォルダのまま確定するか、別のフォルダに変更して確定する。
  6. 「トークスクリプト」シートが解析され、次の章で説明する編集画面が自動的に開く。

2回目以降作業フォルダを開く

一度取り込んだ台本を Excel なしで再編集したいとき

「台本(Excel)からテキストを作成」セクションの 作業フォルダを開く をクリックし、以前作成した作業フォルダを選ぶと、その中の text フォルダの内容を読み込んで同じ編集画面を開けます。Excel ファイルは不要です。text フォルダ自体を選んでしまった場合は、一つ上の階層を作業フォルダとして自動的に読み替えます。text フォルダが見つからない、または中身が空の場合は、画面上に理由が警告として表示されます。

05

スクリプトの確認と編集、保存

「トークスクリプト編集」画面で内容を見直し、テキストファイルとして書き出します

前の章の操作で「トークスクリプト編集」という別ウィンドウが開きます。メイン画面はブロックされず、並行して操作できます。画面上部には、現在保存されている Polly の音声設定が表示されます(例:「現在の Polly 出力設定:日本語(ja-JP)、neural、Tomoko」)。

表は ページ番号(読み取り専用)・トークスクリプト・操作(再生・生成)の3列です。

  1. 内容を確認・修正したい行の「トークスクリプト」のセルをクリックする。
  2. テキストエリアを持つ編集ダイアログが開くので、内容を書き換えて OK を押す。この時点ではまだファイルには書き込まれず、画面上のデータだけが更新される。
  3. すべての行を確認し終えたら、ツールバーの 保存 をクリックする。
  4. その時点の全行が <作業フォルダ>/text/<作業フォルダ名>_<ページ番号>.txt として書き出される(既存ファイルは無条件に上書きされる)。
ⓘ

ページ番号の列はこの画面からは編集できません。番号を直したい場合は Excel 側の値を修正し、4章の手順をやり直してください。また、シート上で削除した行があっても、以前に書き出し済みの .txt ファイルは自動では削除されません。

06

一括変換

編集した全ページのスクリプトを、まとめて音声化します
  1. 「トークスクリプト編集」画面の 一括音声出力 をクリックする。
  2. まず自動的に現在の内容が 5章と同じ形で text フォルダへ保存される(表示中のテキストと生成される音声が必ず一致するようにするため)。
  3. 対象のいずれかのページに mp3 が既に存在する場合、「既存のmp3ファイルを上書きします。よろしいですか?」という確認ダイアログが表示される。OK で続行、中止 で何も上書きせず処理を終了する(直前のテキスト保存はそのまま残る)。
  4. 最大10件まで同時並行で Amazon Polly に音声合成をリクエストし、<作業フォルダ>/mp3/<作業フォルダ名>_<ページ番号>.mp3 として書き出す。ボタン横には [完了数/全体数] の進捗が表示される。
  5. 途中でやめたい場合は、表示される 中止 ボタンをクリックする。実行中のリクエストが終わった時点で処理が打ち切られる。
  6. いずれかのページでエラーが発生すると、その都度エラー内容を示すダイアログが表示され、続行 か 中止 を選べる。
ⓘ

一括音声出力の出力形式は常に mp3 固定です(メイン画面の Output Format 設定とは連動しません)。生成が完了した行は、その場で 再生 ボタンが使えるようになります。

07

個別変換

1ページだけ音声を作り直す、または再生して確認します
  1. 「トークスクリプト編集」画面で、対象行の 生成 ボタンをクリックする。
  2. その行だけが自動的に保存された上で音声化され、<作業フォルダ>/mp3/<作業フォルダ名>_<ページ番号>.mp3 が上書き(または新規作成)される。1件だけの明示的な操作のため、上書き確認ダイアログは表示されない。
  3. 生成が終わると、同じ行の 再生 ボタンが使えるようになる。クリックするとその場で音声を再生して確認できる。
ⓘ

対応する mp3 がまだ無い行では、再生 ボタンは灰色表示で押せません。

08

PPTファイルの指定

音声を埋め込む先の PowerPoint ファイルと、mp3 の場所を指定します

メインウィンドウ(トークスクリプト編集画面ではなく最初の画面)の「PowerPointへの音声埋め込み」セクションで操作します。

  1. PowerPointファイルを選択 をクリックし、埋め込み先の .pptx ファイルを選ぶ。
  2. 選択すると同時に、同じフォルダ内に <元のファイル名>_音声埋め込み.pptx という処理用コピーが自動的に作成される(既に同名のコピーがあれば上書き)。元の pptx ファイルは一切変更されない。
  3. ボタンの隣に赤字で元ファイル名と出力先ファイル名が表示される。以降の作業はすべてこの処理用コピーに対して行われる。
  4. MP3フォルダを指定 をクリックし、埋め込みたい mp3 が入っているフォルダ(通常は6章で作成した <作業フォルダ>/mp3)を選ぶ。
09

埋め込みの実行

スライドの表示順とページ番号を突き合わせ、自動再生の音声として書き込みます

前章の2つ(PowerPointファイルと MP3フォルダ)が両方指定されていると、音声を埋め込む ボタンが押せるようになります。対応付けは「スライドが何番目に表示されるか」と「mp3ファイル名末尾のページ番号」の一致で決まります。

表示順 3番目のスライドslide?.xml
↔
ページ番号が一致…_3.mp3
  1. 音声を埋め込む をクリックする。
  2. 各スライドについて、対応する mp3 の再生時間を取得 → 音声を埋め込む(再生アイコンなどの見た目は一切表示されない)→ スライドの自動送り時間を「音声の長さ + 3秒」に設定、という処理が1枚ずつ行われる。
  3. ボタン横に [現在/全体] の進捗が表示され、完了すると「処理完了」と表示される。
  4. 処理が終わると、出力された _音声埋め込み.pptx の場所がエクスプローラーで自動的に開く。
ⓘ

対応する mp3 が無いスライド、対応するスライドが無い mp3、ページ番号を読み取れない mp3 はそれぞれスキップされ、ログ欄に警告として表示されます(1件のスキップやエラーで全体は止まりません)。すでにアニメーション設定を持つスライドには自動再生の追加をスキップし、警告を表示します(音声自体は埋め込まれるため、必要であれば PowerPoint 側で自動再生を手動設定できます)。

⚠

生成された pptx を PowerPoint で開いた際に「修復が必要」という表示が出ることがあります。その場合も音声の埋め込み自体は保持されることが多く、自動再生の設定だけが失われている可能性があります。スライドショーのタイミング設定を PowerPoint 側で確認・再設定してください。

10

その他の使い方

Excel を使わず、すでに用意した .txt ファイルを直接音声化する方法とアンインストール

メイン画面の「ファイルまたはフォルダから音声出力」セクションでは、Excel の台本を経由せず、手元にある .txt ファイルをそのまま Amazon Polly で音声化できます。Language Code・Engine・Voice ID・Output Format の選び方は共通です。

Language Code
既定値 日本語(ja-JP)。実在する言語のみプルダウンに表示
Engine
既定値 neural。選んだ Language Code に対応するものだけ表示
Voice ID
既定値 Tomoko。Language Code と Engine の両方に対応するものだけ表示
Output Format
既定値 mp3。mp3 / ogg_vorbis / pcm から選択

上から順に選択肢が絞り込まれるため、存在しない組み合わせは選べません。一覧は 音声一覧を再取得 で最新の状態に更新できます。

10-1TXTファイルの指定と変換

.txt ファイルを1つだけ音声化する

  1. TXTファイルを選択 をクリックし、変換したい .txt ファイルを1つ選ぶ。
  2. 必要に応じて Language Code・Engine・Voice ID・Output Format を選ぶ。
  3. 変換開始 をクリックする(音声一覧の取得が完了し、ファイルが選ばれていないと押せない)。
  4. <選んだファイルと同じフォルダ>/mp3/<元のファイル名>.<拡張子> として出力される。拡張子は選んだ Output Format により mp3 / ogg / pcm に変わるが、出力先のフォルダ名は常に mp3。既に同名ファイルがある場合は上書きされる。
ⓘ

長い文章は 2900文字を目安に、句点・感嘆符・疑問符・改行の直後で自動的に分割して Polly に送信し、結果を1つの音声ファイルに結合します。

10-2TEXTフォルダの指定と一括変換

フォルダ内の .txt ファイルをまとめて音声化する

  1. TEXTフォルダを選択 をクリックし、.txt ファイルが入ったフォルダを選ぶ。
  2. 必要に応じてオプションを選び、変換開始 をクリックする。
  3. フォルダ内のすべての .txt ファイルが対象になる。ファイルごとに「変換中 → 完了 / エラー」の状態が一覧表示され、画面上部に [i/全体数] の進捗が表示される。
  4. 1件のファイルでエラーが起きても処理は止まらず、次のファイルの変換に進む。

10-3アンインストール

Windows標準の方法でアプリを削除する

  1. Windows の「設定」→「アプリ」→「インストールされているアプリ」(または「コントロールパネル」→「プログラムのアンインストール」)を開く。
  2. 一覧から「Polly Autogen」を探して選択し、アンインストールを実行する。
  3. アンインストール時、音声設定や編集画面の表示位置などアプリ内部の設定データもあわせて自動的に削除される。
⚠

次のものはアンインストールしても削除されません。残しておきたい場合は事前に別の場所へコピーしてください:
・~/.aws/credentials に保存した AWS のアクセスキー(3章で入力した内容)
・Excel から作成した作業フォルダ、書き出した .txt / .mp3 ファイル
・音声を埋め込んだ _音声埋め込み.pptx
