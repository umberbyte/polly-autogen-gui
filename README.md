# Polly Autogen

Excel の台本(トークスクリプト)を [Amazon Polly](https://aws.amazon.com/jp/polly/) でナレーション音声に変換し、PowerPoint の各スライドに「自動再生される音声」として埋め込むための Windows / Mac 対応デスクトップアプリ(Electron製)です。

すでに用意した `.txt` ファイルを直接音声化する、単純なテキスト読み上げツールとしても使えます。

より画面イメージ付きの詳しい手順は [`docs/user-manual.html`](docs/user-manual.html) も参照してください。本READMEはその要約・最新版です。

## 動作環境

- Windows 11 / macOS
- Amazon Polly を呼び出せる AWS アカウント(IAMユーザーのアクセスキー)
- インターネット接続

## インストール

配布された `Polly Autogen Setup *.exe`(Windows)または `.dmg`(Mac)を実行してください。Windows版はワンクリックインストールで、ウィザード操作は不要です。完了するとデスクトップとスタートメニューに「Polly Autogen」のショートカットが作成されます。

## 起動

デスクトップまたはスタートメニューの「Polly Autogen」アイコンから起動します。起動すると同時に Amazon Polly から利用可能な音声一覧を自動取得します(取得が完了するまで変換系のボタンは押せません)。リージョンは `ap-northeast-1`(東京)に固定されており、変更はできません。

## 基本的な使い方

Excel の台本からナレーション付きPowerPointを作るまでの、一般的な流れです。

### 1. AWSアカウントの設定

画面最上部の「設定」セクションで、Amazon Pollyを呼び出すためのアクセスキーを登録します。

1. **[AWSアカウントの設定]** をクリックする。
2. ダイアログに **Access Key ID** と **Secret Access Key** を入力する(いずれもマスクされないプレーンテキスト欄です)。
3. **[保存]** をクリックすると、`~/.aws/credentials` の `[default]` セクションに書き込まれます(他のプロファイルやコメントはそのまま残ります)。

複数プロファイルを使い分けたい場合などは、隣の **[設定ファイルを編集]** からOS標準のテキストエディタで直接編集できます。

> **Secret Access Key は第三者に共有しないでください。**

### 2. トークスクリプト(Excel)の取り込み

「台本(Excel)からテキストを作成」セクションを使います。

1. **[Excelファイルを選択]** をクリックし、`.xlsx` / `.xls` ファイルを選ぶ。
2. Excel と同じ場所に、ファイル名と同じ名前の作業フォルダが提案されます(既に同名フォルダがある場合は `(2)` `(3)`… と自動的に別名になり、既存の作業内容を誤って上書きしません)。
3. 「作業フォルダを選択してください」という確認ダイアログで **[OK]**。
4. 続くフォルダ選択ダイアログで、提案されたフォルダのまま確定するか、別のフォルダに変更して確定する。
5. **「トークスクリプト」という名前のシート**が解析され、スクリプト編集画面が自動的に開きます。

Excel シートの要件:

- シート名は **「トークスクリプト」** 固定。
- 先頭10行以内に、セルの文字列が完全一致で **「ページ」** となっている列(ページ番号)と、文字列に **「トークスクリプト」** を含む列(本文)のヘッダーが必要です(列の位置は自由。固定のA列/F列である必要はありません)。
- ヘッダー行より下の行のうち、ページ番号列が整数値(または整数を返す数式)で、本文列が空でない行だけが取り込まれます。それ以外の行は無視されます。

2回目以降、同じ台本をExcelなしで再編集したい場合は **[作業フォルダを開く]** から既存の作業フォルダを選べば、`text` フォルダの内容を読み込んで同じ編集画面を開けます。

### 3. スクリプトの確認・編集・保存

取り込むと「トークスクリプト編集」という別ウィンドウが開きます(メイン画面と並行して操作可能)。画面上部には現在のPolly音声設定(言語・エンジン・音声)が表示されます。

- 表は **ページ番号**(読み取り専用)・**トークスクリプト**・**操作**(再生/生成/保存)の3列。
- スクリプトのセルをクリックすると編集ダイアログが開きます。内容を書き換えて **[OK]** で画面上のデータに反映されます(この時点ではまだファイルに書き込まれません)。
- ツールバーの **[保存]** で全行を `<作業フォルダ>/text/<作業フォルダ名>_<ページ番号>.txt` として書き出します(既存ファイルは無条件に上書き)。
- 各行の **[保存]** ボタンでその行だけを個別に保存することもできます。未保存の変更がある行は、この行保存ボタンが目立つ色で表示されます。

> ページ番号の列はこの画面からは編集できません。番号を直したい場合はExcel側を修正し、取り込みをやり直してください。

### 4. 一括変換・個別変換

- **一括変換**: ツールバーの **[一括音声出力]** をクリックすると、全行がまず自動保存された上で、最大10件まで同時並行でPollyに音声合成をリクエストし、`<作業フォルダ>/mp3/<作業フォルダ名>_<ページ番号>.mp3` に書き出します。既存mp3がある場合は上書き確認ダイアログが出ます。処理中は **[中止]** ボタンでキャンセルできます。エラーが起きた行は都度ダイアログで続行/中止を選べます。
- **個別変換**: 各行の **[生成]** ボタンで、その行だけを音声化できます(自動保存してから実行、上書き確認なし)。
- 生成済みの音声がある行は **[再生]** ボタンが有効になり、再生中は表示が **[停止]** に切り替わります。
- スクリプトを編集した後で音声を再生成していない行は、**[生成]** ボタンが目立つ色になり「音声がスクリプトの内容より古い」ことを知らせます。

### 5. 読み上げ速度の部分調整(SSML)

トークスクリプトの一部だけ読み上げ速度を変えたい場合に使います。

- 編集ダイアログでテキストの一部を選択して右クリックすると、再生速度のメニュー(50% 〜 200%のプリセット、または任意の%)が表示され、選んだ範囲だけ速度を変更できます。
- 速度を設定済みの範囲は色つきで表示され、右クリックで変更・解除(**[タグを解除]**)できます。
- 全行まとめて速度を変えたい場合は、ツールバーの速度プルダウンで % を選び **[全行に適用]** をクリックすると、全行のスクリプト全体に一括で速度が設定され、自動的にテキストファイルへ保存されます。

内部的には `<prosody rate="N%">…</prosody>` というタグとしてテキストファイルにそのまま保存され、音声合成時にSSMLとして送信されます。速度指定を含むスクリプトは、通常の長文自動分割(後述)の対象外になります。

### 6. PowerPointへの音声埋め込み

メイン画面の「PowerPointへの音声埋め込み」セクションを使います。

1. **[PowerPointファイルを選択]** で `.pptx` を選ぶ。選択と同時に、同じフォルダ内に `<元のファイル名>_音声埋め込み.pptx` という処理用コピーが自動作成されます(元ファイルは変更されません)。
2. **[MP3フォルダを指定]** で、埋め込みたいmp3が入っているフォルダ(通常は手順4で作成した `<作業フォルダ>/mp3`)を選ぶ。
3. 両方指定すると有効になる **[音声を埋め込む]** をクリックする。

対応付けは「スライドの表示順序」と「mp3ファイル名末尾のページ番号」の一致で決まります(3番目に表示されるスライドには `..._3.mp3` が埋め込まれます)。各スライドには見た目に何も表示されない極小の透明アイコンとして音声が埋め込まれ、スライド開始と同時に自動再生、スライドの自動送り時間は「音声の長さ + 3秒」に設定されます。対応するmp3/スライドが無いものはスキップされ、ログに警告が表示されます。完了すると出力ファイルの場所が自動的に開きます。

> 生成したpptxを開いた際に「修復が必要」と表示されても、多くの場合は音声の埋め込み自体は保持されます。その場合はPowerPoint側でスライドショーの自動再生設定を確認してください。

## その他の使い方

Excel を使わず、すでに用意した `.txt` ファイルをそのまま音声化する場合は、メイン画面の「ファイルまたはフォルダから音声出力」セクションを使います。Language Code・Engine・Voice ID・Output Format(mp3 / ogg_vorbis / pcm)は上から順に選択肢が絞り込まれます。

### TXTファイル単体の変換

1. **[TXTファイルを選択]** で `.txt` を1つ選ぶ。
2. オプションを選び **[変換開始]**。
3. `<選んだファイルと同じフォルダ>/mp3/<元のファイル名>.<拡張子>` に出力されます(既存ファイルは上書き)。

長い文章は2900文字を目安に、句点・感嘆符・疑問符・改行の直後で自動分割してPollyに送信し、結果を1つの音声ファイルに結合します。

### TEXTフォルダの一括変換

1. **[TEXTフォルダを選択]** で `.txt` が入ったフォルダを選ぶ。
2. オプションを選び **[変換開始]**。
3. フォルダ内の全 `.txt` ファイルが対象になります。1件のエラーで全体は止まらず、次のファイルへ進みます。

## アンインストール

Windowsの「設定」→「アプリ」→「インストールされているアプリ」(または「コントロールパネル」→「プログラムのアンインストール」)から「Polly Autogen」を選んで削除します。アプリ内部の設定データ(音声設定・ウィンドウ状態など)もあわせて削除されます。

以下は削除されません。残しておきたい場合は事前に別の場所へコピーしてください。

- `~/.aws/credentials` に保存したAWSのアクセスキー
- Excelから作成した作業フォルダ、書き出した `.txt` / `.mp3` ファイル
- 音声を埋め込んだ `_音声埋め込み.pptx`
